# Viva Questions & Answers

1. What is Pandas?
Pandas is a Python library used for data manipulation and analysis.

2. What is a DataFrame?
A DataFrame is a two-dimensional table-like data structure in Pandas.

3. How do you read a CSV file?
Using `pd.read_csv("filename.csv")`.

4. How do you find missing values?
Using `df.isnull().sum()`.

5. How do you remove duplicate rows?
Using `df.drop_duplicates()`.

6. What does `fillna()` do?
It replaces missing values with a specified value or statistic.

7. Why is median used for Age?
Median is less affected by extreme values than the mean.

8. Why is mode used for City?
Mode gives the most frequently occurring category.

9. What is filtering?
Filtering selects rows that satisfy a condition.

10. How is a new column created?
Assign a value or calculation to a new DataFrame column.

11. What is Matplotlib?
A Python library for creating visualizations.

12. What is Seaborn?
A Python visualization library built on Matplotlib, especially useful for statistical graphics.

13. What is data wrangling?
The process of cleaning, transforming, and preparing data for analysis.

14. What is the purpose of this project?
To clean and analyze a messy student dataset using Python and Pandas.
